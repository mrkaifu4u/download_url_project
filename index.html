● Settings

Keys are stored only in this browser's localStorage. They are never sent to any server except RapidAPI when you press Fetch, and never committed to git.

⚠ Never paste a real key into any file. Put it here, in Settings. If a key ever leaks into a public repo, regenerate it on RapidAPI immediately.
