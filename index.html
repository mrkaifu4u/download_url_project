● Video to Audio Converter

Paste a video URL above (or pick a local file to see its name) and press Convert — the audio stream returned by the API is downloaded as MP3 / M4A. WAV is not returned by the API: if you pick WAV, the MP3 stream is saved instead and the app says so.

Converting…

Honest note: a browser cannot transcode video locally, so a local file upload is not converted on your device — use the video URL above to extract audio via the API. The quality you pick is requested from the API where it is supported; the API returns the audio stream it has. WAV is never transcoded here: if you pick WAV and the API returns no WAV stream, the MP3 stream is saved instead and the app says so.

● Settings

Keys typed here are stored only in this browser's localStorage. They are sent only to RapidAPI when you press Fetch.

⚠ Built-in key is public. This app ships with a RapidAPI key built in (config.js), added by the owner so visitors can fetch without pasting one. Anyone can view it in the public repo, and every Fetch counts against the owner's quota. A key typed here overrides the built-in one. If the quota is abused, rotate the key on RapidAPI.
