● API Management

One row per real RapidAPI host from the app config. Usage is counted from this browser's quota records plus backend totals; 0 when there is none.

⚠ Built-in key is public. This app ships with a RapidAPI key built in (config.js), added by the owner so visitors can fetch without pasting one. Anyone can view it in the public repo, and every Fetch counts against the owner's quota. Rotate the key on RapidAPI if it is abused.

Failed requests: 0 — failed fetches are not stored in v1, so this is 0 unless the backend reports some.

● API keys (this browser only)

Set a different RapidAPI or Scrappa key to use on this browser instead of the built-in ones — for example after rotating a key. Leave a field empty to keep its current key. Clearing removes the override and the built-in key is used again. This only affects this browser; other visitors still use the built-in keys.
